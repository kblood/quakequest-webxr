WebXR Ports

Classic engines rebuilt for the browser. Each port supports ordinary flatscreen play and can add immersive WebXR without replacing its desktop controls. Game files selected from your machine stay local to your browser.

Available

QuakeQuest WebXR

Launch the included Quake shareware episode, or select the id1 folder from a Quake installation you own. Choose flatscreen/WASM or tracked-controller WebXR from the launcher.

Open launcher

Surreal Engine

A shared Unreal Engine 1 runtime for Unreal Tournament and Unreal Gold, with flat WASM/WebGPU and optional WebXR. Its launcher imports a local game folder; original game data will not be hosted here.
