Shared engine architecture

VR is an extension of the engine, not a replacement for its renderer, controls, or menus. The browser build reuses the same game/runtime code; WebXR adds a provider only when an immersive session is active.

Game data and desktop packaging

Legal data boundary

Quake can offer its explicitly redistributable shareware data. Unreal Engine 1 game files are not hosted; the launcher asks the player to select an installation they own and stores imported data locally.

One web build, several shells

The hosted installable web app comes first. Electron or WebView2 can later wrap the same flat WASM launcher, but native OpenXR remains the dependable PC-VR path instead of assuming desktop wrappers expose WebXR.
