Surreal Engine

The data-free browser release runs the shared Unreal Engine 1 runtime in flat WebGPU mode and can enter WebXR through either direct WebGPU layers or a Quest-compatible WebGL presentation bridge.

  • Local-folder import for owned retail data and the supported UT99 348, Unreal 200, and Deus Ex 1002f demos
  • No retail or demo game data is hosted; users supply their own lawful local files
  • Tracked controller proxies, exact menu laser/contact, intro/menu handoff, and mouse fallback integrated
  • Browser OpenAL/Web Audio playback, explicit audio unlock, mute, volume, and lifecycle handling integrated
  • Flat mode is automated-tested; physical Quest/WebXR behavior remains a hardware validation gate

Shared engine architecture

VR is an extension of the engine, not a replacement for its renderer, controls, or menus. The browser build reuses the same game/runtime code; WebXR adds a provider only when an immersive session is active.

Roadmap and release gates

Integrated foundation

Shared baseline

The unified integration passes all 30 registered native tests plus the browser launcher, import, persistence, direct-WebXR, WebGL-bridge, packaging, and corresponding-source suites.

Owned flat boot validated

Quest and owned-data validation

A real 496-file GOG UT99 folder validates, persists, materializes, and reaches the launcher. The generic post-Play import error was traced to Emscripten mutating a deliberately frozen argument array, not to the selected folder. Mutable native arguments, bounded browser audio voices, trusted-input pointer lock, exact canvas binding, and separate folder-scan diagnostics are integrated. A second optional-ABI probe that left Emscripten's runtime aborted was also corrected. The retained GOG profile now boots and renders. Physical Quest stereo/FOV, timing, controls, menus, intro travel, exit/re-entry, and audio remain hardware gates.

Ongoing hardware validation

Next release validation

Continue physical Quest controller, HUD, weapon, save, and title-isolation checks, and keep every public package data-free unless separate redistribution permission is established.

Game data and desktop packaging

Legal data boundary

Quake can offer its explicitly redistributable shareware data. Unreal Engine 1 game files are not hosted; the launcher asks the player to select an installation they own and stores imported data locally.

One web build, several shells

The hosted installable web app comes first. Electron or WebView2 can later wrap the same flat WASM launcher, but native OpenXR remains the dependable PC-VR path instead of assuming desktop wrappers expose WebXR.
